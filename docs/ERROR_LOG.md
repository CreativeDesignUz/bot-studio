### Как фиксировать новую ошибку
1. Добавить строку с новым `BS-NNN` (не переиспользовать ID).
2. Указать точный проект, URL без секретов, дату, версию/commit, ожидаемый и фактический результат.
3. Для исправления приложить PR, CI run, доказательство staging E2E. Переводить в CLOSED только после проверки.

**Нельзя:** копировать в Git журнал содержимое cookies, JWT, Telegram initData, номера телефонов, адреса, API-токены или полные персональные данные.
