# Design QA

- Source visual truth: пользовательский референс дашборда из текущего чата и существующий интерфейс Bot Studio.
- Implementation: `http://127.0.0.1:4173/onboarding`.
- Viewport: мобильная компоновка Codex in-app Browser, приблизительно 478 × 850 CSS px.
- State: выбор типа бота; дополнительно просмотрен мобильный кабинет.
- Full-view evidence: экран визуально открыт в in-app Browser; отдельный файл браузерного снимка недоступен через текущий capture API.
- Focused comparison: типографика, отступы, карточки, радиусы, цвета и нижнее главное действие проверены визуально в открытом превью.

## Findings

- Исправлена P1-проблема переключателя: нижний лист был вложен в sticky-header и обрезался его containing block. Лист перенесён в `document.body` через portal.
- Новый onboarding следует текущим токенам Bot Studio: светлый фон, белые карточки, чёрная главная кнопка и фиолетовый акцент.
- Мобильный экран выбора типа визуально не переполняется; главное действие остаётся доступным снизу.
- Проверка полного интерактивного пути инструментом Browser заблокирована: селекторные клики в текущем мобильном IAB-сеансе не меняют React state, хотя клиентский `useEffect` подтверждает гидратацию. Сборка и lint проходят.

## Comparison history

1. P1: мобильный список ботов обрезался верхним header. Исправление: portal в `document.body`; исходная причина устранена в коде.
2. P2: Telegram SDK менял атрибуты `<html>` до гидратации. Исправление: `afterInteractive` и `suppressHydrationWarning`; предупреждение гидратации исчезло.
